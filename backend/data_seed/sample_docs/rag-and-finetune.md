# RAG 与模型微调知识

## RAG 检索增强生成

RAG（Retrieval-Augmented Generation，检索增强生成）的核心思想是：
先从知识库中检索与问题相关的资料，再让大模型基于这些资料生成回答。
RAG 能显著缓解大模型的幻觉问题，让回答可溯源、可验证。

RAG 的典型流水线包括：文档解析、文本分块、向量化入库、混合检索、重排序、生成与引用标注。
混合检索通常将向量检索与 BM25 关键词检索融合，兼顾语义相关性与词面匹配。
BM25 是一种经典的基于词频与文档长度的信息检索排序算法，是关键词检索的代表方法。

## 模型微调

大模型微调的常用方法包括全量微调（Full Fine-tuning）与参数高效微调（PEFT）。
LoRA 是最流行的参数高效微调方法：它冻结原模型权重，通过注入低秩矩阵来学习增量，
大幅降低显存与数据需求。LLaMA-Factory 是流行的微调框架，支持 LoRA、QLoRA 等方法，
可以通过 YAML 配置文件定义 SFT 训练流程，把领域问答数据训练进模型。

RAG 与微调是互补的两种优化路线：RAG 适合知识频繁更新的场景，微调适合沉淀领域风格与格式。
