# 向量数据库与嵌入模型知识

## 向量数据库

向量数据库是专门用于存储、索引和检索向量化数据的数据库系统。
向量数据库支持基于语义相似度的近邻搜索，是大模型 RAG 应用的核心组件。
ChromaDB 是一个开源向量数据库，轻量易用，支持持久化存储与元数据过滤，
非常适合本地开发与中小规模知识库场景。

常见的向量检索距离度量包括余弦相似度、内积与欧氏距离。
向量数据库通常使用 HNSW 等近似最近邻索引算法来加速检索。

## BGE 嵌入模型

BGE（BAAI General Embedding）是智源研究院开源的中文语义向量模型系列。
BGE 可以把文本映射为高维语义向量，使语义相近的文本在向量空间中距离更近。
bge-small-zh-v1.5 是其中的小规模中文模型，CPU 即可运行，适合企业本地部署。
BGE 模型常与向量数据库搭配，为 RAG 系统提供文档与查询的向量化能力。
